# BlazorDbzPersonagem — .NET Blazor Application

Aplicação Blazor desenvolvida para consumir a API pública de Dragon Ball (`dragonball-api.com`) e exibir dados de um personagem através do seu ID.

## 🚀 Funcionalidades

- Consulta endpoints de personagens (`https://dragonball-api.com/api/characters/{id}`).
- Exibe **Nome**, **Planeta de Origem** e a lista de **Transformações**.
- Interface reativa com suporte a seleção de ID pelo utilizador.
